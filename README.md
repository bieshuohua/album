# 艺术画廊网站

这是一个用于展示摄影和绘画作品的简体中文响应式网站，UI 参考 [Talva 模板](https://talva-fluid-demo.squarespace.com/)，采用黑白配色和窄间距的等高图片排版。

## 功能特点

- 响应式设计，适配移动端和桌面端
- 跟随系统深色/浅色主题，并记住手动选择
- 保持图片原始比例的作品墙与图片懒加载
- 全部作品、摄影、绘画、觉觉专题分类与数量展示
- 大图查看、加载状态与失败提示
- 键盘导航、关闭后焦点恢复和手机横向轻扫
- 手动播放或暂停《小欣之歌》

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid, 媒体查询)
- JavaScript (原生)
- 内联 SVG 图标（无需第三方图标字体）

## 使用方法

1. 克隆或下载本项目
2. 在浏览器中打开 `index.html` 文件
3. 开始浏览艺术作品

## 自定义

- 要添加新的图片，请在 `script.js` 文件中的 `galleryData` 数组中添加新的图片对象
- 图片数据只需填写 `src`、`category`、`title`，无需维护宽高；加载后自动读取原始比例，通过 CSS 自适应排列
- 未加载的图片使用统一占位比例，可通过 `.gallery-grid` 的 `--gallery-placeholder-ratio` 调整
- 可以通过修改 `styles.css` 中的 CSS 变量来自定义主题颜色、页面边距与图片间距
- 响应式断点可以在 `styles.css` 中的媒体查询部分进行调整
